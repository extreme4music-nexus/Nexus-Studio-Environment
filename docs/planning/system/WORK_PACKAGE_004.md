# WP-004 — Преглед на сесии и одлуки

Статус: завршено, 2026-10-22. Една заокружена задача, потоа извештај и стоп до нова корисничка инструкција.

Цел: сесиите и одлуките што веќе ги чува Workspace да бидат читливи во Studio, со целосен текст, датуми, извор, статус и врска со сесија. Прегледот користи вчитан immutable Project, без нови filesystem повици или друга шема.

Критериуми:
- [x] Табови за насока, сесии и одлуки; долги текстови и навигација со тастатура.
- [x] Празни состојби, чистење при смена на проект и буквален приказ на текст.
- [x] Прегледот не создава ревизии и не го губи незачуваниот опис.
- [x] Reload обновува податоци; save го задржува избраниот запис ако постои.
- [x] Реални Workspace тестови, визуелна проверка, триплатформски CI и документација.

Надвор од овој пакет: внес/уредување/бришење записи, module diagnostics, Nexus мозок, NeuraFS, audio и нов SDK. Следната задача бара ново „продолжи“ од корисникот.
