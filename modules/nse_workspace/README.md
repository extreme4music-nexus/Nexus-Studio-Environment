# Workspace module

Проекти, сесии, одлуки и asset-reference метаподатоци зад јавниот `WorkspacePort`, со Runtime lifecycle adapter. Constructor е без resource side effects; јавниот service reference е стабилен и проверува дали модулот работи.

[Упатство](../../docs/workspace/README.md), [архитектура](../../docs/workspace/ARCHITECTURE.md), [recovery](../../docs/workspace/RECOVERY.md) и [verification](../../docs/workspace/VERIFICATION.md).

Нема media bytes, NeuraFS, AI модел или UI во овој модулски пакет.
